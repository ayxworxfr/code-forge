# CodeForge 开发进度规划

## 1. 项目目标

- **背景**：项目主链路已可用，当前进入模板能力增强与体验优化阶段
- **本期目标**：
  1. 维护并扩展内置模板能力（含 Go + Gin + GORM）
  2. 持续优化前端交互一致性与可用性
  3. 完成端到端生成链路稳定性回归
- **非目标**：
  - 不做用户登录/权限系统
  - 不支持 MySQL 之外的数据库
  - 不做在线部署/CI/CD
- **验收标准**：
  1. 能通过前端创建数据源并测试连接
  2. 能选择表和模板，预览生成代码
  3. 能一键下载完整的 ZIP 代码包
  4. 所有内置模板能生成可编译的实际代码
